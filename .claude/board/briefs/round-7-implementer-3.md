Plan:
1. `lib/sandbox-rules.ts`: `type JudgmentRule = "capex_over_5000" | "second_december_bill" | "intercompany_approval"`; `type JudgmentCall = { rule: JudgmentRule; why: string }` (`why` in plain English with the numbers, e.g. "€6,850.00 of equipment coded to opex cost center 4711; over €5,000 it is capex (0400)", using `eur` from sandbox.ts); `CAPEX_LINE = 5000`; `judgmentCalls(invoice, history = HISTORY, costCenters = COST_CENTERS): JudgmentCall[]` in that rule order:
   - capex_over_5000: `total(invoice) > CAPEX_LINE` and the invoice's cost center kind is "opex".
   - second_december_bill: the invoice is dated in December and `history` has an invoice from the same supplier dated earlier in the same year and month (string dates; don't depend on the local time zone).
   - intercompany_approval: the cost center kind is "intercompany".
   An unknown cost center counts as neither opex nor intercompany. Comment that this is the oracle for tests and the sandbox, not something the agent sees.
2. `lib/autopilot.ts`: types `AgentExport`, `ExportGuardrail`, `ExportStep` exactly per the shape above; `type Decision = { verdict: "routine" } | { verdict: "judgment"; guardrailId: string | null; why: string }`; `type Decide = (invoice: Invoice, guardrails: ExportGuardrail[]) => Promise<Decision>`; `type PostAction = { invoiceId: string; costCenter: string }`; `type ForYou = { invoiceId: string; guardrailId: string | null; rule: string; askWhom: string; expertWords: string; why: string }`; `type Plan = { post: PostAction[]; forYou: ForYou[] }`.
3. `plan(invoices: Invoice[], exp: AgentExport, decide: Decide): Promise<Plan>`: only `status === "open"` invoices, one `decide` call at a time in invoice order (deterministic; output in invoice order). Fail closed, every case below goes to `forYou`, never to `post`:
   - `decide` throws or rejects → `why` "The agent couldn't decide, so a person should." (guardrailId null, rule "", askWhom "", expertWords "").
   - the answer isn't a valid `Decision` (null, unknown verdict, wrong types) → `why` "The agent's answer wasn't clear, so a person should."
   - `verdict: "judgment"` → `forYou` with the matched guardrail's `rule`, `ask_whom`, and `expert_words_english || expert_words`, and the decision's `why`; a `guardrailId` not in the export keeps the decision's `why` and empty rule/askWhom/expertWords.
   - the export has no guardrails at all → nothing is posted: every open invoice goes to `forYou` with `why` "This Work Map has no guardrails yet, so the agent can't tell routine from judgment." and `decide` is not called.
   Only a valid `{verdict: "routine"}` gives `post: {invoiceId, costCenter: invoice.costCenter}`. Also export a pure `isDecision(value: unknown): value is Decision`.
