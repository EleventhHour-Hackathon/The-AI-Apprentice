Plan:
1. `autopilot_decide.py`, module docstring on the fail-closed rules. Constants `MODEL = os.getenv("AUTOPILOT_MODEL", "gpt-4.1")`, `COULD_NOT_DECIDE` and `NOT_CLEAR` with exactly the UI's texts from `ui/lib/autopilot.ts`, `NO_GUARDRAILS` likewise.
   - `prompt(invoice, history, export) -> list[messages]` (pure): a system message (you are an accounts-payable agent; post only when none of the expert's guardrails applies; if any might apply, or you are unsure, answer judgment with that guardrail's id; never invent rules) and a user message with JSON of every guardrail (`id, kind, rule, applies_when, ask_whom, expert_words_english or expert_words`), the steps (`title, decision, judgment`), the invoice and the supplier's history. Everything passes through `privacy.redact_deep` first. The invoice's contact is never in it (the body model has no such field, step 2).
   - `parse(text, guardrail_ids) -> dict` (pure): JSON `{"verdict", "guardrail_id", "why"}` → `{"verdict": "routine"}` only when verdict is exactly "routine"; verdict "judgment" with a known id → `{"verdict": "judgment", "guardrailId": id, "why": redact(trimmed why, ≤300 chars)}`; anything else (not JSON, unknown verdict, judgment with an unknown or empty id, missing why) → `{"verdict": "judgment", "guardrailId": None, "why": NOT_CLEAR}`.
   - `class Unavailable(Exception)` for "the model can't be used at all": raised when `OPENAI_API_KEY` is unset/empty (message "The autopilot needs an OpenAI key (OPENAI_API_KEY) on the backend. Nothing was posted.") and on `openai.APIConnectionError`/`openai.APITimeoutError` ("Couldn't reach OpenAI, so the autopilot can't decide. Nothing was posted.").
   - `Complete = Callable[[list], Awaitable[str]]`; `async def decide(invoice, history, export, complete: Complete | None = None) -> dict`: no guardrails → `{"verdict": "judgment", "guardrailId": None, "why": NO_GUARDRAILS}` without calling anything; else `text = await (complete or _openai_complete)(prompt(...))` then `parse`. `Unavailable` propagates; any other exception → `logger.warning` and `{"verdict": "judgment", "guardrailId": None, "why": COULD_NOT_DECIDE}`. `_openai_complete` uses `AsyncOpenAI(api_key=..., timeout=20)` with `temperature=0` and a strict json_schema (`verdict` enum routine/judgment, `guardrail_id` string, "" for none, `why` string).
2. `autopilot_router.py`: `router = APIRouter(prefix="/api/v1", tags=["Autopilot"])`; `POST /work_maps/{work_map_id}/decide` (async def; the store read goes through `run_in_threadpool`). Pydantic bodies (extra fields ignored, so a `contact` sent by mistake is dropped): `InvoiceIn {id, supplier, country, date, due, orderRef, lines: [{description, qty, unit}] (max 50), costCenter, costCenterName, assetNumber, comment}` with string max lengths, and `history: [{id, date, amount, note}]` (max 20, default []). Load the map (404 "Work Map not found"; store error → `_store_unavailable`), `agent_export.to_json(map)`, call `decide`. `Unavailable` → 503 with its message as `detail`. 200 → the Decision dict.
3. `ui/lib/autopilot-api.ts` (no React; no import of sandbox-rules):
   - `toDecideBody(invoice, history = HISTORY)` → `{invoice: {...without contact and status/note, plus costCenterName from COST_CENTERS}, history: HISTORY rows of the same supplier other than this invoice}`.
   - `class AutopilotUnavailable extends Error` (a 503 with the backend's `detail`).
   - `decideRemote(workMapId, {timeoutMs = 20000, fetchImpl = fetch} = {}): Decide`: POST `${BACKEND_URL}/api/v1/work_maps/{id}/decide` (`encodeURIComponent`), AbortController timeout. Network error/timeout/non-2xx → throw (503 → `AutopilotUnavailable(detail)`); 200 resolves only if `isDecision(body)`, otherwise throws. The `guardrails` argument of `Decide` is ignored (the backend reads the same map).
   - `fetchAgentExport(id): Promise<AgentExport>` via `agentExportUrl(id, "json")`.
   - `runAutopilot(invoices, exp, decide) -> Promise<{plan: Plan; unavailable: string | null}>`: wraps `decide` to remember the first `AutopilotUnavailable` message and, once one is seen, stops calling the backend (later invoices throw at once, so they land in For you), then calls `plan`.
   - `applyPlan(invoices, plan, now) -> {invoices, log: Log[]}` (pure): for each `post` action whose invoice is still `open` and still has that `costCenter`, set `status: "posted", note: ""` and add the log line `Invoice <id> posted by the autopilot to <code> <cost center name>`; any other invoice is unchanged, and so is any invoice changed since the plan was made. Returns new log lines newest first, like the page's log.
